# CONTROL ESCOLAR

Sistema web integral desarrollado para la gestión de procesos académicos y administrativos de una institución educativa.

## Descripción del Proyecto
El proyecto permite el control colaborativo de las siguientes secciones:
- **Alumnos:** Inscripciones, reinscripciones, bajas, cambios de carrera, pagos y evaluación docente.
- **Profesores:** Captura de calificaciones parciales, finales, exámenes extraordinarios y reporte de asistencias.
- **Administrativos Nivel A:** Gestión (CRUD) de materias, horarios de profesores y alumnos.
- **Administrativos Nivel B:** Control (CRUD) de pagos, becas y titulación.
- **Director de Carrera:** Gestión de profesores, asignaturas, planes de estudio y postgrados.
- **Secretario Académico:** Generación de reportes de matrícula, bajas, deserciones y aprovechamiento académico.
