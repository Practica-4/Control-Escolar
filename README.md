# CONTROL ESCOLAR

Sistema web integral de gestión académica y control escolar para instituciones educativas, diseñado para administrar los procesos de alumnos, profesores, personal administrativo y directivo con diferentes niveles de acceso y módulos especializados.

---

## 📋 Descripción del Proyecto

La aplicación permite llevar el control detallado de las operaciones institucionales clave, estructuradas por perfiles de usuario:

1. **Alumnos:** Inscripciones, reinscripciones, bajas, cambios de carrera, pagos y evaluación de profesores[cite: 1].
2. **Profesores:** CRUD de calificaciones parciales, finales y de exámenes extraordinarios, reporte de calificaciones y asistencias[cite: 1].
3. **Administrativos Nivel A:** Realizan CRUD de materias, de horarios de profesores y de alumnos[cite: 1].
4. **Administrativos Nivel B:** CRUD de pagos, CRUD de becas y titulación[cite: 1].
5. **Director de Carrera:** CRUD y evaluación de profesores, CRUD de carreras y planes de estudio, y CRUD de postgrados[cite: 1].
6. **Secretario Académico:** Reportes de matrícula, reportes de bajas y deserciones, reportes de becas, reporte de aprovechamiento por grupo, carrera y nivel académico (licenciatura y maestría)[cite: 1]. Cuenta con la vista de **HOME** con el menú de navegación de cada elemento[cite: 1].

## 🛠️ Tecnologías y Estructura
* **Backend:** Laravel (PHP)
* **Frontend:** Tailwind CSS, HTML5 y JavaScript
* **Control de Versiones:** Git / GitHub

## 📁 Módulos Principales del Home
* Cambios de carrera
* CRUD de calificaciones parciales
* CRUD de materias
* CRUD de carreras y planes de estudio
* Carreras y nivel académico
